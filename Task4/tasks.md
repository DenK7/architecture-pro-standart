# Список крупных задач по системам

Задачи для планирования MVP на 6 месяцев (депозиты онлайн из задания 3 и передача ставок в кол-центры из этого задания)
и целевого решения на горизонте года. Идентификаторы совпадают с карточками в [roadmap.drawio](roadmap.drawio).

Тип задачи: **MVP** — открытие депозитов онлайн (задание 3); **Новый кейс** — ставки в кол-центре банка и партнёрском КЦ;
**Цель** — целевое решение на 6–12 месяцах; **Запуск** — тестирование и запуск.

## Критический путь нового кейса

T1 → T3 → T8 → T10 → T26 → T27 → T32 для партнёрского КЦ и T8 → T21 → T22 → T31 → T32 для кол-центра банка.
Кол-центры должны быть готовы до старта маркетинговой кампании, поэтому задачи кейса завершаются в 5–6 месяце, вместе с MVP.
